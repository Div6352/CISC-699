2.1 Introduction

The development of autonomous software-engineering systems has expanded the role of artificial intelligence from developer assistance toward increasingly autonomous execution of software-development tasks. Recent systems demonstrate the ability of language-model-based agents to interact with repositories, tools, execution environments, and software-development workflows. Research such as SWE-agent and OpenHands illustrates this transition from conventional language generation toward agent-based software engineering in which an AI system can plan, act, observe execution results, and modify software artifacts. 2.3 Autonomous Software-Engineering Agents

Artificial intelligence has increasingly moved from providing isolated developer assistance toward systems capable of performing multiple stages of software engineering. Modern coding agents can interact with files, repositories, command-line tools, tests, and other execution environments. This evolution changes the role of an AI model from a system that primarily produces suggestions to a system that can participate in an executable software-development process.

SWE-agent represents an important example of this transition. The system investigates how an agent-computer interface can provide language-model agents with effective mechanisms for interacting with software repositories and development tools. Its emphasis on repository navigation, file modification, command execution, and testing demonstrates that successful software-engineering agents require more than language generation; they require interaction mechanisms that connect reasoning to executable actions. (Yang et al., 2024) (Yang et al., 2024)

2.5 Natural-Language Reasoning and Decision Making

ReAct demonstrated a framework in which language models interleave reasoning and actions. This work is important because it illustrates how language-model reasoning can influence external actions rather than remaining entirely within generated text. (Yao et al., 2023)

For autonomous software engineering, this principle enables an agent to reason about a repository, perform an action, observe the resulting state, and determine what to do next.
