Missing and Invalid Workflow Data Safety Evaluation

Experiment: Missing and Invalid Workflow Data Handling
Date: November 6, 2026

OBJECTIVE

Evaluate whether the deterministic semantic-contract router prevents unintended workflow transitions when required workflow data is missing or has an invalid data type.

EXPERIMENTAL SETUP

The experiment used two validated semantic contracts:

Contract 1:
Source: Check Tests
Target: Deploy Code
Condition: tests_passed equals True

Contract 2:
Source: Check Tests
Target: Fix Code
Condition: tests_passed equals False

The router was tested with six workflow-data scenarios.

TEST SCENARIOS AND RESULTS
