--------------------------------------------------
1. EXPERIMENT OBJECTIVE
--------------------------------------------------

The purpose of this experiment was to evaluate the repeatability of deterministic semantic contract routing and the reliability of automatic execution trace generation across repeated executions.

The experiment examined whether identical predefined workflow conditions consistently produced the same routing decisions while generating separate JSON execution traces.

4. EXPECTED BEHAVIOR
--------------------------------------------------

The system was expected to:

- Produce the correct routing decision for each workflow state.
- Return routing status ROUTED.
- Select exactly one matching contract.

- Preserve routing and validation information in the saved traces.
