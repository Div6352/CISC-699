7. RESEARCH INTERPRETATION
--------------------------------------------------

The experiment demonstrates that the prototype rejects a routing decision when multiple semantic contracts match the same workflow state.

Instead of arbitrarily choosing one destination, the router returns an explicit AMBIGUOUS status and leaves the selected next node unset.

The automatic tracing wrapper also preserves evidence of this rejected decision.

These results support the research objectives of deterministic transition evaluation, ambiguity handling, and execution traceability.

--------------------------------------------------
8. LIMITATIONS
--------------------------------------------------

The experiment evaluated one predefined ambiguous routing scenario.

It did not test all possible forms of ambiguity, large workflow graphs, concurrent execution, or unexpected runtime failures.

The experiment demonstrates safe ambiguity rejection for the tested scenario rather than comprehensive correctness across all possible workflow configurations.
